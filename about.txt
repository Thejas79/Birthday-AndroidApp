How it’s made — architecture & components

UI layer: Activities and/or Fragments with XML layouts. Lists usually use RecyclerView.

Data layer:

Room (recommended) — Entities, DAO, Database class; or

SQLiteOpenHelper — manual SQL if Room not used.

Business layer / Repository: a small class that mediates between UI and DB.

Scheduling/Reminders: AlarmManager sets alarms for reminders; BroadcastReceiver listens and triggers a Notification via NotificationManager.

Persistence of settings: SharedPreferences for small app settings.

Dependency management: Gradle (declares external libraries like Material, Room, lifecycle, Glide/Picasso for images).

App lifecycle & background: Android lifecycle-aware components (ViewModel, LiveData) help keep UI in sync; optional WorkManager for scheduled background tasks.
